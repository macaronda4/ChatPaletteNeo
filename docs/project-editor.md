# Project編集画面

- 左側は幅240のExplorer、中央は本文、右側は話者・送信タブと操作ボタンです。
- フォントはBIZ UDPゴシック（`BIZ UDPGothic`）の通常ウェイトに統一しています。未インストールの環境ではOSの代替フォントで表示されるため、指定フォントで表示するにはインストールが必要です。
- 本文はURL入力欄と同じ幅、話者と各ボタンは「接続」と同じ幅になります。
- Explorerのファイルをクリックすると開き、青い背景と枠で開いているファイルを示します。
- Projectを開いた直後は全ディレクトリを折りたたみます。必要な階層だけ展開してください。
- 「前へ」「次へ」はExplorerの上から順のファイルへ移動します。折りたたまれたフォルダ内も対象です。
- 「保存」または `Ctrl + S` で話者・本文・送信タブを保存します。「送信」は指定タブへ編集中の内容を送信します。話者が空欄（空白のみも含む）なら「KP」、送信タブが空欄なら「メイン」を使います。送信時の補完によって入力欄や保存内容は書き換えません。本文が空欄なら送信しません。
- 編集中に他のファイル・Projectへ切り替える場合やアプリを終了する場合は、保存／破棄／キャンセルを確認します。

## 作成と保存

本文と話者の入力欄では、`Ctrl + Z` で元に戻し、`Ctrl + Shift + Z` または `Ctrl + Y` でやり直せます。履歴は入力欄ごとに独立しています。別ファイルを開くと履歴を初期化し、保存では履歴を保持します。元に戻した後に新しく編集すると、やり直し履歴は破棄されます。

`Ctrl + N` でも新規ファイルの名前入力画面を開けます。作成先は開いているファイルと同じフォルダ、ファイル未選択時はProjectルートです。作成後は新しいファイルを開きます。未保存の変更の確認をキャンセルした場合、ファイルは作成しません。

名前入力画面は表示直後に入力欄へフォーカスを移すため、クリックせず入力できます。ディレクトリの右クリックメニューからも名前を変更でき、配下の実ファイルとCPNの相対パスを更新します。本文欄などメイン画面をクリックした場合やフォーカスを戻した場合は、右クリックメニューを閉じます。

ファイルの右クリックメニューから「送信」を選ぶと、そのファイルを開いて通常の送信処理を行います。別ファイルへ切り替える場合は未保存の変更を確認し、キャンセル時は送信しません。現在開いているファイルを送信する場合は、編集中の話者・本文を使用します。未接続時や送信中はメニューの「送信」が無効になります。

Explorerを右クリックしてファイル／ディレクトリを作成できます。ディレクトリ上ではその中、ファイル上では同じ階層、空白部分ではルートに作成します。右クリックメニューには作成先が表示されます。名前の入力画面ではEnterで作成、Escでキャンセルでき、使用できない名前は画面内に理由を表示します。ファイル名には必要に応じて `.json` を付けます。

新規Projectは、左上の「新規」から開始します。Explorer上部の「Project保存」を押すと保存場所とProject名を選べます。既存Projectでは同じ `.cpn` を上書きします。新規Projectで最初にファイルの「保存」を押した場合も、Projectの保存先を選びます。

ファイルの右クリックメニューから「ファイル名変更」「ファイル削除」を選べます。名前変更は編集内容を保持し、実ファイル名とCPNの相対パスも変更します。同名項目がある場合は上書きしません。削除は確認後に実ファイルとツリーから削除し、開いているファイルなら編集欄を閉じます。未保存の編集がある場合は削除確認に明記します。保存済みProjectではCPNも更新し、その書き込みに失敗した場合は元のファイルとツリーへ戻します。

本文のJSON形式（旧ファイルに `tab` がない場合は「メイン」として読み込みます）:

```json
{"speaker": "話者名", "text": "本文\n次の行", "tab": "メイン"}
```

`.cpn` の内容はツリーの配列です。ファイルの保存先は `.cpn` のあるフォルダを基準にExplorerの階層から決定し、`data.path` に相対パスを記録します。

```json
[
  {
    "text": "シーン1",
    "type": "directory",
    "data": {"path": "シーン1"},
    "children": [
      {
        "text": "導入.json",
        "type": "file",
        "data": {"path": "シーン1/導入.json"},
        "children": []
      }
    ]
  }
]
```

この場合、本文は `.cpn` と同じフォルダの `シーン1/導入.json` に保存されます。

保存済みProjectでは新規作成やD&Dのたびに `.cpn` も更新します。D&Dでは実ファイル／ディレクトリも移動します。移動先に同名の項目がある場合は中止し、Project保存に失敗した場合は移動前へ戻します。編集中の本文はD&Dで自動保存せず、編集欄に保持します。

`type` のない旧形式も読み込めます（子あり＝directory、子なし＝file）。空ディレクトリは `"type": "directory"` を明示してください。旧形式に `data.path` があっても、保存先はExplorerの階層を基準とします。既存の本文JSONは上記の相対パスに置いてください。本文ファイルがない場合はエラーを表示し、空の内容で置き換えません。

## バックグラウンド接続

1. URL欄へ `https://ccfolia.com/rooms/ルームID` を入力し、「接続」を押します。
2. 専用スレッドでヘッドレスChromiumを起動し、匿名でルームへ接続します。ブラウザのウィンドウは開きません。
3. 接続中からURL欄をロックします。接続成功後はボタンが「切断」に変わり、ファイルを開いている場合に「送信」が有効になります。
4. 「切断」でルームのページを閉じます。ログインセッションはメモリ上に残し、次の接続で再利用します。アプリ終了時にはブラウザとセッションを破棄します。切断完了後、URL欄が編集可能になり、ボタンは「接続」に戻ります。

「ログイン（任意）」からアプリ内のメールアドレス／パスワード入力欄を開き、「ログイン」を押してください。URLが空欄ならログインだけを行い、その後URLを入力して接続できます。URLが入力済みならログイン後にルームへ接続します。別ウィンドウは開きません。未ログインの場合は通常の「接続」で匿名接続します。ログイン済みの場合は同じセッションを再利用します。サーバー側の有効期限やブラウザ障害によって再ログインが必要になる場合があります。

前回送信したメールアドレスだけをユーザー設定 `ChatPaletteNeo/preferences.json` に保存して次回表示します（WindowsはAPPDATA、その他はXDG_CONFIG_HOMEまたは `~/.config` 配下）。パスワードとCookieは保存しません。設定の書き込みができない場合でも、その起動中はメールアドレスを保持します。アプリを終了すると認証セッションは破棄します。接続処理中・接続中・ログイン処理中はログインボタンを無効化します。

SNSログイン・追加認証・CAPTCHAには未対応です。権限のないアカウントは、ログインしてもアクセスできません。普段使いのブラウザのログイン状態は利用しません。

送信先は右側の「送信タブ」入力欄で指定します。ルームに存在するタブ名を入力してください。指定したタブが見つからない場合や同名候補が複数ある場合は送信を中止し、別タブへは送信しません。本文は改行を含めて一括入力します。送信中は連打を防ぎ、自動再送は行いません。入力欄が空になった場合でもサーバーへの到達は保証できないため「送信操作完了（到達未確認）」と表示します。結果不明の場合は、再送する前にココフォリア側のログを確認してください。

接続処理は日本語版のチャット画面に依存します。入力欄・送信ボタンの仕様が変わった場合はエラーになります。実ルームへの投稿・実アカウントでのログインは未検証です。

追加タブは並べ替え用の `role="button"` を持つため、タブ一覧内の `button[aria-selected]` とタブ名ラベルの完全一致で特定します。検証ルームの「情報」で候補が一つであること、クリック後の選択状態、メインへの復帰を確認しています。

検証ルームで「メイン」のアクセシブル名が通知数を含む `メイン 0` になることを確認しました。タブ名の完全一致ではなく、タブ一覧内の `button#main[role="tab"]` を指定し、選択後は `aria-selected` の更新を待ちます。候補なし・複数候補の場合は要素数を表示し、先頭タブへの代替送信は行いません。話者欄はラベル「名前」ではなく、実画面で確認した `input[name="name"]` を使います。

入室時の案内が操作を妨げる場合は、「7日間再表示しない」を含む案内ダイアログ内の「閉じる」を押します。チェックボックスは変更せず、ログイン画面や未知のダイアログを自動で閉じません。タブ操作中に案内が遅れて出た場合に限り、閉じてからタブ選択を一度だけ再試行します。メッセージ送信は再試行しません。

通常のルームURLは `/chat` 専用画面のURLへ変換して接続します。最初から `/chat` または `/chat/` の付いたURLも利用でき、`/chat` を重複させません。ユーザー提供の検証ルームで、通常画面と `/chat` のHTML、案内の閉じる操作、`/chat` での情報→メインへの切り替えと選択状態をブラウザで確認しました。ヘッドレスのPythonアプリ全体を実ルームに接続する試験と、実際の投稿は行っていません。自動テストではブラウザをモックしています。

## 実行・検証

### Explorerの描画

新規作成では同じ階層の名前と新しい項目のパスだけを検証します。既存の全ファイルに対するディスク確認・ディレクトリ作成処理を繰り返さず、新規項目とCPNを原子的に保存します。CPN保存に失敗した場合は新規項目を取り消します。CPN形式は従来と同じです。ツリー全体のJSON保存は残るため項目数に比例しますが、再帰シリアライズの重複も除去しています。

Linux・実JSON 1,000ファイルで、新規ファイル／ディレクトリを交互に8回作成した中央値は203.61ms→15.02msでした（`d03b87a`との比較、ファイルとCPN書き込みを含むストア処理のみ、GUI描画は含まない）。

ファイル選択ではExplorerを作り直さず、選択が変わった2行のみを更新します。作成・移動・名前変更時も既存の行ウィジェットを再利用し、追加・削除・折りたたみで表示対象が変わった行だけを作成／破棄します。ドラッグ中は16ms間隔で最新位置の処理をまとめ、マウスを離した時は最後の位置を即時反映します。移動先は行位置のキャッシュから検索し、同じ移動先では強調表示をやり直しません。キャッシュはツリー更新・サイズ変更・ドラッグ開始時に無効化します。入力中のステータス表示も、内容が変わった部品だけを再描画します。

Linux/Xvfb・150ファイルの未保存Projectで、変更前（`c1df89c`）と比較しました。ファイル選択10回の中央値は1435.11ms→4.35ms、並べ替え＋描画更新10回は1421.02ms→10.06ms、同一移動先でのドラッグ更新30回は119.20ms→0.03msでした。描画の完了待ちを含みますが、ディスク保存や通信時間は含みません。Windowsや別のファイル数で同じ数値になることは保証しません。初めて開くProjectは表示対象の行を生成するため、その負荷は残ります。

Python 3.9以降とTkが必要です。

```sh
python -m pip install -r requirements.txt
python -m playwright install chromium
python main.py
python -m unittest discover -s tests -v
```

GUIテストにはディスプレイが必要です。Linuxでは `xvfb-run -a python -m unittest discover -s tests -v` でも実行できます。ディスプレイのない環境ではGUIテストのみスキップされます。

接続処理のテストはブラウザをモックするため、Chromiumをインストールしなくても実行できます。Linuxで実際に接続する場合、Chromiumのシステム依存ライブラリも必要です（Playwright公式のインストール手順を参照）。
